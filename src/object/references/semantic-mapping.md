# Semantic mapping

| Established Skill concern | Abstract meaning | NickLinney package realization |
|---|---|---|
| `skill_id`, version, name | semantic identity | object record plus manifest identity/version |
| composition | capability Object plus Execution Model | object record and contract |
| execution mode | consumption/execution profile | object record mode vocabulary |
| embedded contract | pre-execution inspectability | `contract.md` and contract reference |
| context packet fields | implementation compatibility profile | source register and explicit compatibility decision |
| provenance | source-to-rule lineage | projections, comparison, source register |
| validation | qualified evidence classes | validation report and lifecycle |
| lifecycle | state and nonclaims | lifecycle and unresolved records |

No field is duplicated merely to appear complete. Package-envelope fields describe representation; semantic fields describe the Skill type.
