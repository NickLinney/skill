# NickLinney Skill Abstract Object

This package defines the technology-independent `Skill` Abstract Object and its NickLinney/Object implementation mapping. It is an abstract specification package, not a concrete runnable Skill.

Entrypoint: `ABSTRACT-OBJECT-SPECIFICATION.md`

The package follows the NickLinney/Object `1.0.0-alpha.1` package convention. Its manifest, schemas, source register, contract, lifecycle, validation evidence, and ordinary SHA-256 inventory are included. Runtime agent metadata is package metadata only; `SKILL.md` is intentionally not present because this package does not represent a runnable Skill.
